D'CELUP CHICKEN CRISPY - MID PROJECT WEB DESIGN

Isi project:
- index.html      : Home
- about.html      : About + lokasi
- menu.html       : 12 menu + harga
- order.html      : Order + Product Showcase/Gallery + WhatsApp
- contact.html    : Contact + feedback rating 1-5
- css/style.css   : Custom CSS
- images/         : logo, ilustrasi produk, dan foto lokasi asli

Cara menjalankan:
1. Ekstrak folder.
2. Buka index.html di browser, atau buka folder melalui VS Code + Live Server.
3. Internet diperlukan agar Bootstrap, Bootstrap Icons, dan Google Fonts dari CDN dapat dimuat.

Catatan:
- Website ini adalah website statis untuk tugas Web Design. Tidak ada backend/database.
- Tombol WhatsApp diarahkan ke 0853-4503-4011.
- Pesanan diminta minimal 3 jam sebelum membeli.
- Foto location.jpg adalah foto lokasi yang diberikan oleh pemilik/project.
- File produk SVG adalah visual lokal agar project tetap memiliki lebih dari 6 gambar tanpa bergantung pada gambar eksternal.
- Jika memiliki foto produk asli, file SVG dapat diganti dengan foto JPG/PNG tanpa mengubah struktur halaman.

Teknologi:
HTML5, CSS3, Bootstrap 5.3.8, Bootstrap Icons.
